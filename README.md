# VisionGuard

VisionGuard is an AI-powered CCTV surveillance system for real-time security monitoring.
It uses YOLO-based object detection to identify intrusions and suspicious activity.
Detected incidents can be recorded as evidence for further review.
A React dashboard provides a simple control-room interface for monitoring.

## How visionGaurd Works?

VisionGuard receives a live CCTV camera feed for continuous monitoring.
The YOLO AI model detects people and other objects in the video.
When the configured intrusion condition is detected, VisionGuard generates a security alert.
The system captures evidence and stores incident details for review.
The React dashboard displays the live feed, camera status, alerts, and recorded incidents.


## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click **`RUN_VISIONGUARD.bat`**.
4. The required backend and dashboard services will start automatically.
5. Open the displayed dashboard URL in your browser.
